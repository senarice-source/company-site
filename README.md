# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」の企業Webサイトです。
業務システムの受託開発からクラウド基盤の設計・運用までを手がける会社として、事業内容や会社情報を1ページで紹介します。

## ページ構成

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピーと会社紹介 |
| 事業内容 | 受託開発／クラウド基盤構築／プロダクト設計・UX／保守・運用 |
| 自社プロダクト | 自社で提供しているプロダクトの紹介 |
| 開発の流れ | ヒアリング → 要件定義・設計 → 開発 → テスト・リリース → 運用・改善 |
| 数字で見る | 実績を数値で紹介 |
| 会社概要 | 所在地などの会社情報 |
| 採用情報 | バックエンドエンジニア／SRE・インフラエンジニア／プロダクトデザイナー |
| お問い合わせ | お問い合わせフォーム（入力チェックのみのデモで、実際には送信されません） |

## ファイル構成

```
company-site/
├── index.html   … ページ本体（HTML）
├── style.css    … スタイルシート（ライト／ダークモード対応）
├── script.js    … お問い合わせフォームの入力チェックなど
└── README.md    … このファイル
```

## ブラウザで表示する手順

ビルドやサーバーは不要です。HTMLファイルを直接ブラウザで開くだけで表示できます。

### 方法1：エクスプローラーから開く

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Chrome、Edge など）でサイトが表示されます。

ブラウザを選びたい場合は、`index.html` を右クリックして「プログラムから開く」から選択してください。

### 方法2：ブラウザにドラッグ＆ドロップする

1. ブラウザを起動します。
2. `index.html` をブラウザのウィンドウにドラッグ＆ドロップします。

### 方法3：コマンドから開く

PowerShell で `company-site` フォルダに移動し、次のコマンドを実行します。

```powershell
start index.html
```

### 注意事項

- `index.html`・`style.css`・`script.js` は同じフォルダに置いたままにしてください。別々の場所に移動すると、デザインや動作が反映されません。
- フォントは Google Fonts からインターネット経由で読み込みます。オフライン環境では代わりのフォントで表示されます。
